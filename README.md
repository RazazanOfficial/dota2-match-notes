# Dota 2 Match Notes

دفتر فارسی و واکنش‌گرا برای ثبت، مرور و گزارش مچ‌های Dota 2.

## امکانات

- تقویم شمسی هفتگی از شنبه ۳ مرداد ۱۴۰۵
- ثبت و ویرایش بازی، هیرو، بن‌ها، یادداشت و نتیجه
- محاسبه برد، باخت و نرخ برد روزانه و هفتگی
- گزارش متنی مناسب مرور با کوچ
- پشتیبان‌گیری و بازیابی JSON
- ذخیره خودکار در مرورگر
- اجرای آفلاین پس از اولین بارگذاری

## اجرا

پروژه بدون مرحله build اجرا می‌شود:

```bash
python3 -m http.server 8080
```

سپس `http://localhost:8080` را باز کنید.

## تست

```bash
node --test tests/core.test.js
```

## داده‌ها

اطلاعات بازی‌ها در `localStorage` مرورگر ذخیره می‌شوند و در مخزن عمومی قرار نمی‌گیرند.
