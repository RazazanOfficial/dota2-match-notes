# نتیجه اعتبارسنجی بسته کتابخانه خودکار

پایه: `0c01f6c50833f63c36eb155205e7c497d69ed461`.

تغییرات روی یک checkout تمیز از همین کامیت کپی و dependency ها با `npm ci` نصب شدند. نتیجه دستورهای زیر مربوط به همان checkout تمیز است:

| بررسی | نتیجه |
|---|---|
| `npm ci --no-audit --no-fund` | موفق |
| `npm run test:desktop` | ۲۲۲ از ۲۲۲، در ۲۸ فایل |
| `npm run test -w @dota-notes/api` | ۵۱۰ از ۵۱۰، در ۷۲ فایل |
| `npm test` | نوبت وب: ۲۷۹ از ۲۷۹؛ نوبت ریشه: ۶۳۴ از ۶۳۴ |
| `npm run typecheck` | همه workspace ها موفق |
| `npm run desktop:assets:publish` | ۷۶۸ فایل، مجموع ۵۵۷۳۰۱۳۱ بایت |
| `npm run api:build` | موفق |
| `npm run release:prepare -w @dota-notes/api` | موفق |
| `npm run desktop:build` | موفق |
| `cargo test --locked --manifest-path apps/desktop/native-tests/Cargo.toml` | ۱۵ از ۱۵ |
| `cargo test --locked --manifest-path apps/desktop/companion/Cargo.toml` | ۴ از ۴ |
| `git diff --check` شامل فایل های جدید | موفق |
| تطبیق فایل های تغییرکرده با checkout تمیز | یکسان |
| پایان خط فایل های متنی بسته | LF، مطابق `.gitattributes` |
| helper تنظیم env با داده ساختگی | موفق؛ مقادیر دیگر حفظ شدند و دسترسی 600 ماند |

تعداد تست های دستورهای مختلف همپوشانی دارد؛ آنها را به عنوان تعداد تست یکتای کل با هم جمع نکنید.

## مواردی که تست شده اند

- migration واقعی از تاریخچه قبلی و اجرای دوباره migration با PostgreSQL سازگار PGlite؛ بدون حذف داده قدیمی.
- صف گزارش پایان بازی، مهلت پنج دقیقه، جلوگیری از تکرار، بازه زمانی گزارش و credential محدود که دسترسی ورود به حساب نمی دهد.
- باز شدن دوباره رابط، credential پردازش همراه فعال را بی دلیل تعویض نمی کند؛ بستن سریع پنجره نباید آن را از کار بیندازد.
- بازه های تاریخچه و snapshot، جلوگیری از درخواست جزئیات برای مچ موجود و مرز نیمه شب تهران.
- اولویت SQL دانلود در هر دو حالت: مچ در صف تحلیل و مچ جدا از پنج تحلیل قدیمی.
- شروع دانلود آماده حتی وقتی پاسخ `/api/tasks` متوقف شده است.
- رد وضعیت قدیمی صفحه در برابر نسخه جدیدتر تسک، و کنار گذاشتن دانلودهای قدیمی یا ناموفق ذخیره شده.
- انیمیشن عبور پیاپی مرحله ها، تعویض درخواست و نگه داشتن ورود پشت صفحه آماده سازی assets.
- تطبیق تمام فایل های manifest با اندازه و SHA256 سورس و بازنویسی آدرس های ثابت و پویا در build دسکتاپ.
- تشخیص کتابخانه دوم Steam، اعتبارسنجی executable و تشخیص خراب بودن فایل هم اندازه در cache.
- تشخیص رویداد پایان بازی متعلق به کاربر و صف محلی بدون ثبت تکراری.

## محدودیت های صریح این گزارش

این محیط لینوکس است. تلاش برای بررسی target ویندوز به نبود MSVC `lib.exe` و ابزار SDK ویندوز برخورد کرد. بنابراین ساخت نصاب NSIS، تست کامل Tauri روی ویندوز، نصب/حذف واقعی، اجرای Task Scheduler و نمایش واقعی WebView2 در اینجا پاس اعلام نمی شوند.

تست Rust بالا هسته های مستقل را بررسی می کند، نه تمام لایه IPC و پنجره Tauri. مرحله ویندوز راهنمای استقرار و workflow به روز شده `Windows desktop test installer` باید پیش از استقرار اجرا و پاس شوند.

به VPS ها وارد نشده ایم، env واقعی عوض نشده و تست زنده Steam/GSI، اینترنت ایران و ParsPack انجام نشده است. تست های پذیرش پس از استقرار در `deploy-automatic-library.fa.md` آمده اند. دریافت خودکار نیازمند launch option بازی و اجرای دوباره آن است؛ صرف نصب companion، دریافت رویداد را ثابت نمی کند.

بررسی ظاهری نهایی پنل در WebView2 نیز باید روی ویندوز انجام شود. علت CSS همپوشانی دکمه کپی در کد اصلاح شده، اما این گزارش ادعای تایید تصویری WebView2 ندارد.

هیچ commit، push، تغییر DNS، نصب بسته روی VPS یا پاک کردن دیتابیس انجام نشده است.
