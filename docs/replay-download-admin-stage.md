# دانلود Replay و مدیریت آرشیو — پچ مرحلهٔ اول

- صفحهٔ `/replays`: کاربر واردشده یک Match ID را جست‌وجو می‌کند. اطلاعات پایهٔ موجود
  از DB استفاده می‌شود؛ برای Match ID تازه، OpenDota با محدودیت سهمیه و
  cooldown پنج دقیقه‌ایِ جست‌وجوی خارجی خوانده می‌شود. جست‌وجو به‌تنهایی
  Replay دانلود یا Parse نمی‌کند.
- «دریافت Replay» فقط دانلود از Valve/پروکسی و آرشیو در ParsPack را صف می‌کند.
  دکمهٔ «دانلود Replay» پس از تأیید فایل ظاهر می‌شود. دانلود از مسیر داخلی
  سایت stream می‌شود و نیاز به دسترسی عمومی bucket ندارد.
- Performance روی همین صفحه تحلیل مستقل را درخواست می‌کند، بدون اینکه Match
  به ژورنال افزوده شود. در جزئیات Match ژورنال نیز دکمهٔ Replay دیده می‌شود.
- کلیدهای جدید `replays/YYYY/MM/DD/MATCH_ID.dem.bz2` هستند. `.dem.bz2`
  پسوند فرمت Replay است؛ بخش نام فایل، فقط Match ID است. فایل‌های قدیمی
  `MATCH_ID_SALT.dem.bz2` جابه‌جا یا پاک نمی‌شوند و از روی کلید DB باز می‌شوند.
- وضعیت `archive_status` در `local_replay_jobs`: `active` فایل ذخیره‌شده،
  `missing` فایلی که خارج از سایت حذف شده یا هنوز آپلود نشده، `deleted` فایلی
  که Super Admin از پنل پاک کرده. اطلاعات تحلیل قبلی پس از حذف Replay حفظ می‌شود.
  هنگام درخواست مجدد برای فایل حذف‌شده، worker دوباره آن را دریافت می‌کند.
- پنل Super Admin فهرست پوشه‌ها/فایل‌ها را صفحه‌به‌صفحه از ParsPack نشان می‌دهد.
  حذف پوشه تمام فایل‌های زیر آن را پاک و ردیف‌های مربوط در DB را `deleted`
  می‌کند. حذف فایل، تأیید صریح در UI می‌خواهد. حذف واقعی فایل برگشت‌پذیر نیست.

## استقرار

پیش از migration `0019_replay_archive_status` و تعویض worker، سرویس replay را
متوقف و بکاپ DB بگیرید. سپس `npm ci`، migration، تست، build و روشن کردن سرویس‌ها.
timer `dota2notes-replay.timer` باید فعال باشد؛ در غیر این صورت درخواست‌ها
`pending` می‌مانند. این پچ secret یا متغیر محیطی جدید ندارد؛ `CLOUD_SPACE_*`
فعلی برای سرویس وب و worker لازم است. `/dev/mock/replays` و
`/dev/mock/replay-archive` پیش‌نمایش بدون دیتابیس هستند و در production 404 می‌دهند.

در تست VPS یک Match ID جدید را در `/replays` جست‌وجو کنید، فقط دریافت Replay
را بزنید و پس از تکمیل از سایت دانلود کنید؛ بعد درخواست تحلیل را ثبت کنید.
حذف آزمایشی فایل از پنل ادمین را روی یک Replay کم‌اهمیت انجام دهید و درخواست
دوباره را بررسی کنید. نبود فایل در bucket به‌تنهایی تضمین نمی‌کند Valve هنوز
Replay قدیمی را دارد.
