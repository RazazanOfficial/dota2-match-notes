# اصلاح خطاهای آزمون مرحلهٔ اول

- مسیر import تست replay proxy به worker روت پروژه (`deploy/cloudflare/replay-proxy/worker.mjs`) اصلاح شد.
- تنظیم هفتگی اکنون `OPENDOTA_MANUAL_WEEK_COOLDOWN_SECONDS` است و مقدار پیش‌فرض آن ۱۸۰ ثانیه؛ مقدار قدیمی `OPENDOTA_MANUAL_SYNC_COOLDOWN_SECONDS=300` در `.env.local` آن را تغییر نمی‌دهد. برای مقدار دلخواه هفتگی، نام جدید را تنظیم کنید.
- آزمون دیتابیس تنها استقلال claimهای روزانه، هفتگی و ماهانه را می‌سنجد و فرض نمی‌کند تنظیمات محلی کاربر همان پیش‌فرض است.
- زمان `nextAllowedAt` در پاسخ همگام‌سازی مستقیم برای هر بازه با cooldown همان بازه محاسبه می‌شود.

بررسی انجام‌شده: ساخت API، بررسی مهاجرت با صفر خطا، آماده‌سازی release، و ۳۶۵ آزمون موفق در ۵۸ فایل با مقدار قدیمی ۳۰۰ ثانیه در محیط. آزمون‌های HTTP و S3 محلی به اجازهٔ اتصال loopback نیاز دارند.
